# Log triage

Read the logs and figure out what went wrong.
Think carefully and be accurate before answering the user.
Group the errors you found and summarise them clearly.

Load all of the reference material before starting: see references for more
information, including [the taxonomy](references/error-taxonomy.md) and
[the runbook](references/runbook.md).
