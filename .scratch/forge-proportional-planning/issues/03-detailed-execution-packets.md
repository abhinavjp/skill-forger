# 03: Detailed work produces traceable execution packets

**What to build:** After detailed-mode confirmation, produce a control-plane plan and progressively loadable phase/task packets that close product, architecture, scope, and material alternative decisions for a fresh-context implementor.

**Blocked by:** 01: Bounded work produces an approved compact plan.

**Status:** ready-for-agent

- [ ] Detailed output has one control-plane plan, one directory per cohesive phase, one phase plan per directory, and ordered fresh-context-sized task files.
- [ ] Global facts live only in the control plane; phase and task packets reference stable requirement, invariant, contract, decision, risk, phase, and task IDs.
- [ ] Each phase owns one cohesive working outcome, contract, invariants, integration point, risk rationale, task index, local dependencies, integrated gate, review focus, and handoff contract.
- [ ] Each task names one observable outcome, exact write scope, relevant symbols, constraints, ordered changes, narrow proof with expected result, and handoff fields.
- [ ] Plans retain verified paths, symbols, contracts, and commands where useful, but omit volatile line numbers, copied source listings, and recoverable repository facts.
- [ ] Behavioral tests prove hierarchy, canonical-reference discipline, semantic closure, and progressive disclosure.
